# Werbe Manager

Mirror dieser WordPress-Erweiterung. Der eigentliche Plugin-Code liegt im Unterordner [`werbe-manager/`](werbe-manager/).

## Quickstart

```bash
# Repository klonen
git clone https://github.com/<dein-account>/werbe-manager.git
cd werbe-manager

# Plugin in WordPress kopieren
cp -R werbe-manager/ /pfad/zu/wordpress/wp-content/plugins/

# WordPress-Backend -> Plugins -> "Werbe Manager" aktivieren
```

Ausführliche Installationshinweise findest du in [`werbe-manager/INSTALLATION.md`](werbe-manager/INSTALLATION.md).
